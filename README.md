# Downwind Call: airfield and aircraft data

Free, open data for [Downwind Call](https://downwindcall.com), the in-sim traffic-circuit coach for MSFS 2024.

- `profiles/airports/` one file per airfield: runways, circuit side, height, size, frequencies, notes
- `profiles/aircraft/` one file per aircraft: speed bands, flaps, limits
- `profiles/README.md` file format and how to measure a circuit from a chart

Browse, read and reuse the data under CC BY 4.0 (see `LICENSE`). Corrections and new airfields are welcome: read `CONTRIBUTING.md`.

**Simulator use only. Never use this data for real-world navigation or flight.**

The Downwind Call application itself is proprietary and is not part of this repository.
`validator.py` and `tools/` are included only so you can check your own contribution.
